# Corresponding source

The public source repository for Goral is
<https://github.com/749755576/goral>. It contains the Rust/Tauri and React
sources, locked dependency manifests, and the native-client acquisition and
verification scripts required to reproduce the application build.

Each distributed binary should identify the exact source commit or release tag
from which it was built. Native Mosh and Eternal Terminal clients retain their
own upstream source and license obligations; see `src-tauri/resources/README.md`
and `THIRD_PARTY_NOTICES.md`.
